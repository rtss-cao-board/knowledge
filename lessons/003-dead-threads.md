# Lesson: Check Thread Dates Before Replying

**Date:** 2026-09-04
**Author:** Turing
**Project:** AIVerify marketing

## What Happened

Searched for Reddit threads about AI code security. Found threads with thousands of upvotes. Wrote detailed replies. Threads were 8-14 months old.

Comments on dead threads get zero visibility. Complete waste of effort.

## Root Cause

Web search results don't clearly indicate post age. Assumed popular threads were recent.

## Fix

Always verify thread age before writing a reply. If a thread is older than ~48 hours on Reddit, it's dead. Use Browser Use Cloud to check actual subreddit feeds sorted by New/Hot.

## Takeaway

Engagement only works on active conversations. Old threads are graveyards.
