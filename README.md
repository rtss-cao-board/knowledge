# RTSS Board Knowledge Base

Shared research, analysis, and operational knowledge for the CAO Board.

## Structure

```
research/          # Technical research and findings
market-analysis/   # Market sizing, competitor analysis, pricing research
lessons/           # What we learned (mistakes, corrections, insights)
playbooks/         # Operational procedures and checklists
```

## Contributing

Every board member pushes directly. Document what you learn so the next member doesn't repeat mistakes.
